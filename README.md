# 서울 연도별 기온 변화 대시보드

서울의 일별 기온 데이터(`seoul_temperature.csv`)를 연도별로 집계해, 평균기온 꺾은선 그래프와 5년 이동평균선을 보여주는 Streamlit 웹앱입니다.

## 주요 기능

1. 연도별 평균기온 꺾은선 그래프
2. 5년 이동평균선을 같은 그래프에 겹쳐서 표시
3. 사이드바의 연도 범위 슬라이더, 그리고 시작·끝 연도를 직접 입력하는 숫자 칸 (슬라이더와 서로 연동되며, 시작 연도가 끝 연도보다 크면 두 값을 자동으로 맞바꿈)
4. 그래프에서 연도 두 곳을 차례로 클릭하면 시작·끝 연도가 자동 지정 (첫 클릭한 연도는 점선으로 표시, 클릭 순서와 관계없이 작은 값이 시작 연도)
5. 키보드 단축키: Esc로 전체 범위(1908~2025) 복귀, Ctrl+←/→로 시작·끝 연도 1년씩 조정
6. 선택 구간의 평균·최고·최저기온 표시 (최고·최저기온은 관측일 함께 표시)
7. 연도별 데이터 표 (접이식)

## 키보드 단축키

| 단축키 | 동작 |
| --- | --- |
| `Esc` | 가장 큰 범위(1908~2025)로 되돌리기. 그래프에서 첫 번째로 클릭해 둔 연도 선택도 함께 취소 |
| `Ctrl` + `←` | 시작 연도 -1 (최솟값 1908에서 멈춤) |
| `Ctrl` + `→` | 끝 연도 +1 (최댓값 2025에서 멈춤) |

- 사이드바에 같은 동작의 버튼이 있어 마우스로 눌러도 됩니다. 단축키는 이 버튼을 대신 눌러주는 방식입니다.
- 키를 계속 누르고 있어도 한 번만 동작합니다.
- macOS에서는 `Ctrl+←/→`가 데스크톱(Spaces) 전환에 쓰이도록 설정되어 있을 수 있습니다. 이 경우 시스템 설정의 키보드 단축키에서 해당 항목을 끄거나, 사이드바 버튼을 사용하세요.
- 입력칸이나 슬라이더에 포커스가 있어도 동작합니다.

## 파일 구성

```
.
├── app.py                  # Streamlit 앱 코드
├── requirements.txt        # 필요한 라이브러리
├── seoul_temperature.csv   # 데이터 (직접 넣어야 함)
└── README.md
```

## 실행 방법

1. 위 파일들을 한 폴더에 둡니다. CSV 파일명은 반드시 `seoul_temperature.csv`로 맞춰주세요.
2. 라이브러리를 설치합니다.

   ```bash
   pip install -r requirements.txt
   ```

3. 앱을 실행합니다.

   ```bash
   streamlit run app.py
   ```

4. 브라우저에서 `http://localhost:8501`이 열립니다.

## 데이터 형식

| 컬럼 | 설명 |
| --- | --- |
| 날짜 | 관측일 (값 앞에 탭 문자가 있어 `strip()`으로 제거) |
| 지점 | 관측 지점 번호 |
| 평균기온(℃) | 일 평균기온 |
| 최저기온(℃) | 일 최저기온 |
| 최고기온(℃) | 일 최고기온 |

## 데이터 처리 방식

- **탭 문자 제거**: 날짜 값 앞뒤의 탭/공백을 제거한 뒤 날짜형으로 변환합니다. 변환되지 않는 행(1개)은 자동으로 제외됩니다.
- **BOM 처리**: 컬럼명 앞의 BOM이 남지 않도록 `utf-8-sig`로 읽습니다.
- **일수가 적은 연도 제외**: 1907년(92일)과 2026년(169일)은 데이터 일수가 적어 제외합니다.
- **결측 구간(1950~1953년)**:
  - 연평균 꺾은선에서는 제외하고 선을 끊어서 표시합니다.
  - 값이 계산되는 해(1950년, 1953년)는 검은색 **x 표시(이상치)**로 따로 표시합니다. 1951년, 1952년은 평균기온이 전부 비어 있어 x 표시도 나타나지 않습니다.
  - 5년 이동평균은 결측 연도가 낀 구간에서 계산하지 않고 끊어서 표시합니다. 그래서 이동평균은 1958년부터 다시 나타납니다.
- **통계 계산**: 선택 구간의 평균·최고·최저기온은 일별 데이터 기준입니다. 사이드바의 체크박스를 켜면 결측 구간(1950~1953년)도 통계에 포함하며, 기본값은 제외입니다.

## 설정값 바꾸기

`app.py` 상단의 상수로 조정할 수 있습니다.

```python
CSV_PATH = "seoul_temperature.csv"
EXCLUDE_YEARS = [1907, 2026]              # 제외할 연도
MISSING_YEARS = [1950, 1951, 1952, 1953]  # 결측 연도
MA_WINDOW = 5                             # 이동평균 기간(년)
```
